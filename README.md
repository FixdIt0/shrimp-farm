# $SHRIMP — The Shrimp Farm

## Concept
A token where creator fees fund a fleet of OpenClaw AI agents ("shrimp") that do visible work. Holders watch their shrimp farm grow. Rides the OpenClaw "raising shrimp" (养虾) trend — 280K+ GitHub stars, biggest open source AI agent in history.

## What the agents do
- SHRIMP-01: Tweet Scout — scans crypto twitter for trends
- SHRIMP-02: Meme Generator — creates and posts memes
- SHRIMP-03: Trend Analyst — analyzes DexScreener/Birdeye data
- SHRIMP-04: Thread Writer — writes and posts X threads
- SHRIMP-05: Wallet Roaster — roasts wallets with real on-chain data

## Pages built
